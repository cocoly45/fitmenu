# 🍽️ FitMenu

**Application de planification de repas pour sportifs**

![FitMenu](https://img.shields.io/badge/Status-Live-green)
![License](https://img.shields.io/badge/License-MIT-blue)

##  Lien direct

👉 **https://cocoly45.github.io/fitmenu/**

## ✨ Fonctionnalités

-  **Menu hebdomadaire** généré automatiquement
- 🥗 **Recettes détaillées** avec étapes de préparation
- 📊 **Calcul des macros** (calories, protéines, glucides, lipides)
- 🛒 **Liste de courses** organisée par catégorie
- 💰 **Estimation du coût** en dollars canadiens
- 🎯 **Filtres alimentaires** (végétarien, sans gluten, riche en protéines...)
- 🌙 **Mode sombre** pour le confort visuel
-  **Design responsive** (mobile et desktop)
- 💾 **Sauvegarde** de plusieurs menus favoris
- 📄 **Export PDF** de ton menu

## 🎯 Objectifs caloriques

| Objectif | Calories/jour |
|----------|--------------|
| Perte de poids | 1800 kcal |
| Maintien | 2200 kcal |
| Prise de masse | 2800 kcal |

## ️ Technologies

- HTML5
- CSS3 (Tailwind CSS)
- JavaScript (ES5)
- jsPDF (export PDF)
- Font Awesome (icônes)

## 📱 Comment utiliser

1. Ouvre l'application dans ton navigateur
2. Choisis tes filtres alimentaires (optionnel)
3. Clique sur "Régénérer le Menu" pour un nouveau menu
4. Explore les recettes en cliquant sur chaque plat
5. Consulte ta liste de courses
6. Exporte en PDF ou partage avec tes amis !
